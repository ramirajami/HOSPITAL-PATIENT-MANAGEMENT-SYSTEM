\# Hospital Patient Management System

\## 1. Project Overview

A desktop application for storing and searching basic patient information and maintaining patient records.

This project is designed as a simple college-level Python desktop application. It uses a graphical user interface built with Tkinter and stores data locally using SQLite. The application is intended for demonstration, academic submission, and basic practical use.

\## 2. Main Objectives

\- Store patient registration information digitally.

\- Search patients using name, phone, or patient ID.

\- Maintain diagnosis and doctor-related information.

\- Reduce dependency on paper-based records.

\- Provide quick access to stored patient data.

\## 3. Main Modules

\- Patient Registration

\- Patient Search

\- Patient Record Display

\- Record Deletion

\- Database Management

\## 4. Technologies Used

\- Programming Language: Python 3

\- GUI Framework: Tkinter

\- Database: SQLite3

\- Programming Style: Event-driven desktop application

\- Database file created automatically: \`hospital.db\`

\## 5. System Requirements

\- Python 3.x

\- Tkinter

\- SQLite3

\- Windows/Linux/macOS

\## 6. Installation and Execution

1\. Install Python 3.x.

2\. Extract the project folder.

3\. Open the folder in VS Code, IDLE, or another Python editor.

4\. Open a terminal in the project folder.

5\. Run:

\`python patient_management.py\`

6\. The SQLite database will be created automatically when the program starts.

7\. Use the GUI to enter sample records and test the features.

\## 7. Important Files

\- \`patient_management.py\` — main Python source code.

\- \`hospital.db\` — SQLite database generated automatically after first run.

\- \`PROJECT_REPORT.txt\` — detailed academic project report.

\- \`README.txt\` — project setup and usage instructions.
